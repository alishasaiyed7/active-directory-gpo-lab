## Interview-Ready One-Liners (You Can Memorize)

---
What is GPO? \
GPO is used to centrally manage user and computer configurations in an Active Directory domain.

Why do we use GPO? \
To enforce security, standardize configurations, and reduce manual administration effort.

Real-life usage? \
Enforcing password policies, disabling USB, mapping network drives, and restricting software installation.

Troubleshooting? \
Use gpresult, rsop.msc, Event Viewer, and verify OU linking and security filtering
